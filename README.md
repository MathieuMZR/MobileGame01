# MobileGame01

A mobile game project built with Unity.

## Getting Started

### Requirements

- [Unity Hub](https://unity.com/download)
- Unity Editor (version to be defined)
- Android Build Support and/or iOS Build Support modules

### Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/MathieuMZR/MobileGame01.git
   ```
2. Open Unity Hub, click **Add**, and select the cloned folder.
3. Open the project with the matching Unity Editor version.

## Project Structure

| Folder | Purpose |
| --- | --- |
| `Assets/` | Game assets: scenes, scripts, prefabs, art, audio |
| `Packages/` | Unity package manifest |
| `ProjectSettings/` | Unity project configuration |

## Building

1. Go to **File > Build Settings**.
2. Select **Android** or **iOS** and click **Switch Platform**.
3. Click **Build** (or **Build And Run** with a device connected).
